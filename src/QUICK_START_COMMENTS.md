# Quick Start Guide - Request Comments

## 🚀 Getting Started with Comments

The Request Comments feature allows employees and admins to discuss requests directly in the portal. Here's how to use it:

---

## 👤 For Employees

### **Viewing & Adding Comments**

1. **Navigate to Request History**
   - Go to Company Portal → "Request History" (📋 icon)

2. **Open Request Details**
   - Click "Details" button on any request
   - Request details modal opens with 2 columns

3. **View Comments**
   - Right column shows "Discussion" panel
   - See all previous comments in chronological order
   - Your comments appear on the right (green)
   - Admin comments appear on the left (teal)

4. **Add a Comment**
   - Type your message in the text area at the bottom
   - Click the Send button (✉️) or press `Ctrl+Enter`
   - Your comment appears immediately
   - Admin receives a notification

### **Use Cases for Employees:**

✅ **Explain unusual requests**
```
"I need this leave because my daughter is graduating and 
the ceremony is on a weekday."
```

✅ **Provide additional context**
```
"The advance is needed urgently for a medical emergency.
I can provide receipts upon request."
```

✅ **Ask questions**
```
"Should I submit a separate request for the return flight,
or include it in this entry permission?"
```

✅ **Respond to admin questions**
```
"The medical report is from Dr. Ahmed at Al-Salam Hospital.
I've attached the signed document."
```

---

## 👨‍💼 For Admins

### **Viewing & Managing Comments**

1. **Navigate to Admin Dashboard**
   - Go to Admin Dashboard → "Requests" tab

2. **Open Request Details**
   - Click the "View" (👁️) button on any request
   - Request details modal opens with 2 columns

3. **View Comments**
   - Right column shows "Discussion" panel
   - See complete conversation history
   - Employee comments appear on the left
   - Your (admin) comments appear on the right (teal)

4. **Add a Comment**
   - Type your message in the text area
   - Click Send or press `Ctrl+Enter`
   - Employee receives a notification immediately

5. **Delete Comments** (Admin Only)
   - Click the "Delete" (🗑️) link below any comment
   - Confirm the deletion
   - Comment is removed permanently

### **Use Cases for Admins:**

✅ **Request clarification before approving**
```
"Can you provide more details about the reason for this leave?
What dates exactly will you be unavailable?"
```

✅ **Ask for documentation**
```
"Please upload the medical report to support this sick leave request.
The report should be from a licensed physician."
```

✅ **Provide feedback on rejections**
```
"This request is rejected because you've already used your annual
leave quota. Please check your leave balance."
```

✅ **Set expectations**
```
"Your advance request is approved. Please note that the amount will
be deducted from your salary over the next 3 months."
```

✅ **Communicate policy**
```
"Entry permissions must be requested at least 48 hours in advance
as per company policy. Please plan accordingly next time."
```

## 💡 Best Practices

### **For Employees:**

1. ✅ **Be Clear & Concise**
   - State your purpose clearly
   - Provide necessary details upfront
   - Use proper grammar

2. ✅ **Be Professional**
   - Maintain respectful tone
   - Avoid emotional language
   - Use proper salutations

3. ✅ **Be Proactive**
   - Anticipate admin questions
   - Provide context for unusual requests
   - Attach supporting documents

4. ✅ **Respond Promptly**
   - Check notifications regularly
   - Respond to admin questions within 24 hours
   - Keep the conversation moving

### **For Admins:**

1. ✅ **Ask Clarifying Questions**
   - Don't assume - ask for details
   - Request documentation when needed
   - Verify unusual requests

2. ✅ **Provide Context**
   - Explain rejection reasons clearly
   - Reference company policies
   - Set expectations for approval timeline

3. ✅ **Be Timely**
   - Respond to employee questions promptly
   - Don't let requests languish
   - Use comments to unblock decisions

4. ✅ **Document Decisions**
   - Use comments to create audit trail
   - Record special circumstances
   - Note any exceptions to policy

## 🎯 Common Scenarios

### **Scenario 1: Sick Leave with Medical Report**

**Employee:**
```
Request: 3 days sick leave
Comment: "I was diagnosed with severe flu. Attaching medical
report from Dr. Sarah at City Hospital."
```

**Admin:**
```
Comment: "Thanks for providing the report. I've verified it with HR.
Your request is approved. Get well soon!"
Action: Approve request
```

---

### **Scenario 2: Emergency Advance Request**

**Employee:**
```
Request: 5000 SAR advance
Comment: "I need this urgently for a family medical emergency.
My father is hospitalized and needs immediate treatment.
I can provide hospital bills as proof."
```

**Admin:**
```
Comment: "Sorry to hear about your father. I've expedited your
request. The amount will be transferred today and deducted
over 6 months. Please submit the bills to HR by end of week."
Action: Approve request
```

---

### **Scenario 3: Unclear Entry Permission**

**Admin:**
```
Comment: "Can you clarify the purpose of this entry permission?
You've requested exit and return on the same day. Are you
traveling abroad or just leaving the office?"
```

**Employee:**
```
Comment: "Apologies for the confusion. I need to visit the
passport office in the morning and will return by 2 PM.
I'm not traveling abroad - just need a few hours for this errand."
```

**Admin:**
```
Comment: "Perfect, that makes sense. Approved. Please ensure
you're back by 2 PM as stated."
Action: Approve request
```

## 🛠️ Troubleshooting

### **Problem: Comments not loading**

**Solution:**
1. Refresh the page
2. Check your internet connection
3. Try closing and reopening the request details
4. Check browser console for errors

---

### **Problem: Cannot send comment**

**Solution:**
1. Ensure you've typed some text
2. Check that you're logged in (session not expired)
3. Try refreshing the page
4. Clear browser cache if issue persists

---

### **Problem: Notification not received**

**Solution:**
1. Check notification bell (🔔) in header
2. Ensure browser notifications are enabled
3. For PWA: Check system notification permissions
4. Refresh the page to sync notifications

---

### **Problem: Delete button not visible (Admin)**

**Solution:**
1. Ensure you're logged in as admin
2. Only admins can see delete buttons
3. Regular employees cannot delete comments
4. Check that you have admin privileges
