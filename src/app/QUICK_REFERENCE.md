# Ya Hala E-Portal - Quick Reference Guide

## 🚀 Phase 1 Features - How to Use

### 1. Notifications System

#### For Employees:
1. Look for the bell icon (🔔) in the top navigation
2. Badge shows unread notification count
3. Click bell to open notification panel
4. Click any notification to mark it as read
5. Use "Mark all as read" to clear all at once

#### For Admins:
- Notifications are automatically created when:
  - Request status changes (approved/rejected)
  - Employee cancels a request
  - System events occur

---

### 2. Bulk Request Processing

#### How to Use:
1. Go to **Admin Dashboard** → **Requests** tab
2. Filter to show only "Pending" requests
3. Check the boxes next to requests you want to process
4. Click "Select All" to select all visible pending requests
5. Click **"Approve All"** or **"Reject All"** button at the bottom
6. Add optional notes (required for rejection)
7. Confirm the action

#### Tips:
- ✅ Only pending requests can be bulk-processed
- ✅ All selected employees will receive notifications
- ✅ You can add the same note to all requests
- ✅ Use filters to narrow down before selecting

---

### 3. PDF Export

#### Requests Report:
1. Go to **Admin Dashboard** → **Requests** tab
2. Apply any filters you want
3. Click **"Export PDF"** button
4. PDF will download automatically

#### Employee Report:
1. Go to **Employee Management**
2. Apply filters if needed
3. Click **"Export PDF"**
4. Professional PDF report downloads

#### Features:
- Ya Hala branding and colors
- Clean table layout
- Page numbers
- Generation date
- Bilingual support

---

### 4. Breadcrumbs Navigation

Automatically appears at the top of most pages showing:
```
🏠 > Dashboard > Current Page
```

- Click any segment to navigate back
- Home icon returns to main page
- Works in both English and Arabic

## 🛠️ For Developers

### Using the Notification System

```tsx
import { useNotifications } from './contexts/NotificationContext';

function MyComponent() {
  const { 
    notifications,      // Array of all notifications
    unreadCount,        // Number of unread notifications
    markAsRead,         // (id: string) => void
    markAllAsRead,      // () => void
    clearNotification,  // (id: string) => void
    refreshNotifications // () => void
  } = useNotifications();

  return (
    <div>
      <p>You have {unreadCount} unread notifications</p>
      {notifications.map(notif => (
        <div key={notif.id} onClick={() => markAsRead(notif.id)}>
          {notif.title}
        </div>
      ))}
    </div>
  );
}
```

### Creating Custom PDF Exports

```tsx
import { exportToPDF } from './utils/pdfExport';

const data = [
  { id: 1, name: 'Ahmed', status: 'Active' },
  { id: 2, name: 'Fatima', status: 'Active' }
];

const columns = [
  { header: 'ID', dataKey: 'id', width: 20 },
  { header: 'Name', dataKey: 'name', width: 60 },
  { header: 'Status', dataKey: 'status', width: 30 }
];

const doc = await exportToPDF(data, columns, {
  title: 'My Custom Report',
  subtitle: 'Generated by Ya Hala Portal',
  orientation: 'landscape',
  headerColor: '#7AC143'
});

doc.save('my-report.pdf');
```

### Adding Bulk Actions to Other Pages

```tsx
import { BulkActionsBar } from './components/BulkActionsBar';
import { useState } from 'react';

function MyDataTable() {
  const [selectedIds, setSelectedIds] = useState<string[]>([]);

  return (
    <>
      {/* Your table with checkboxes */}
      <table>
        <tbody>
          {items.map(item => (
            <tr key={item.id}>
              <td>
                <Checkbox
                  checked={selectedIds.includes(item.id)}
                  onCheckedChange={() => toggleSelect(item.id)}
                />
              </td>
              {/* Other cells */}
            </tr>
          ))}
        </tbody>
      </table>

      {/* Bulk Actions Bar */}
      {selectedIds.length > 0 && (
        <BulkActionsBar
          selectedCount={selectedIds.length}
          selectedIds={selectedIds}
          onClear={() => setSelectedIds([])}
          onSuccess={() => {
            refetchData();
            setSelectedIds([]);
          }}
        />
      )}
    </>
  );
}
```

## 🔌 API Endpoints Reference

### Notifications

```bash
# Get all notifications for an employee
GET /notifications/:employee_id
Response: { success: true, notifications: [...] }

# Mark a notification as read
PATCH /notifications/:id/read
Response: { success: true, notification: {...} }

# Mark all notifications as read for an employee
PATCH /notifications/:employee_id/read-all
Response: { success: true, count: 5 }

# Delete a notification
DELETE /notifications/:id
Response: { success: true }
```

### Bulk Operations

```bash
# Bulk update request statuses
PATCH /admin/requests/bulk
Body: {
  request_ids: ["req1", "req2", ...],
  status: "approved" | "rejected",
  admin_notes: "Optional notes"
}
Response: {
  success: true,
  updated: 10,
  requests: [...],
  notifications: [...]
}
```

## 🐛 Troubleshooting

### Issue: Notifications not appearing
**Solution**: 
1. Check that NotificationProvider wraps your App
2. Verify employee is logged in
3. Check browser console for errors
4. Test backend endpoint directly

### Issue: Bulk operations not working
**Solution**:
1. Ensure requests are in "pending" status
2. Check that checkboxes are visible
3. Verify admin permissions
4. Check network tab for API errors

### Issue: PDF export fails
**Solution**:
1. Check browser supports jsPDF
2. Verify data format is correct
3. Try with smaller dataset first
4. Check console for specific errors

### Issue: Breadcrumbs not showing
**Solution**:
1. Verify component is imported correctly
2. Check items array has valid structure
3. Ensure labels are provided

## 🎓 Best Practices

### Notifications
- ✅ Keep messages concise and clear
- ✅ Use appropriate notification types
- ✅ Include relevant context (request ID, type)
- ✅ Don't spam - batch similar notifications

### Bulk Operations
- ✅ Always add meaningful admin notes
- ✅ Double-check selection before confirming
- ✅ Use filters to narrow scope
- ✅ Process in reasonable batches (<100)

### PDF Exports
- ✅ Apply filters before exporting
- ✅ Use meaningful file names
- ✅ Include generation date
- ✅ Test with sample data first
